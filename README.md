 Network Security Risk Dashboard

This project analyzes enterprise network traffic and converts technical security findings into business risk metrics.

Project Overview

A simulated enterprise network environment was analyzed using packet-level traffic data.

The analysis identifies malicious activity, evaluates protocol-level risks, and estimates expected annual loss from security incidents.

 Key Findings

- Analyzed 10,000 network packets
- Detected 850+ malicious events
- Identified ARP Spoofing, HTTP Credential Exposure, and DNS Poisoning
- Estimated Expected Annual Loss of ₹249.9L
- Compared mitigation strategies using NPV and payback analysis
- Generated executive-ready dashboard outputs
